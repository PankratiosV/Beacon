Beacon is installed

Beacon opens by itself. To start it later, open it from Applications or Launchpad.

macOS asks a few questions the first time. Allow these so every feature works:

  • Screen Recording: lets Beacon read LightBurn's Laser panel. If you aren't asked, turn on Beacon in System Settings › Privacy & Security › Screen & System Audio Recording, then quit and reopen Beacon. You can skip this if you only use LightBurn's API (LightBurn 2.2+).
  • Local Network: needed for the Wi-Fi stack light, smart plugs and the phone dashboard.
  • Notifications: needed for pop-up alerts when a job finishes.

Keep LightBurn's Laser panel visible (Window › Laser) when reading the screen.
